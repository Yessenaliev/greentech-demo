# GreenTech — демо фермы

Демо-версия приложения для гидрофермы. **Все данные условные.**

Сайт: https://yessenaliev.github.io/greentech-demo/

## Что внутри

- `index.html` — вся демо-версия в одном файле: трёхмерная сцена фермы, помещения специалистов, задачи, экономика с пересчётом.
- Формулы (VPD, DLI, насыщение кислородом, экономика) лежат в блоке `<script>` внизу файла, в разделах «расчёты» и «экономика».
- Условные данные — там же: массивы `TASKS`, `CROPS`, объект `E`.

## Как запустить локально

Открыть `index.html` в браузере. Нужен интернет: библиотека three.js и шрифты подгружаются из сети.

## Как обновить сайт

Заменить `index.html`, затем:

```
git add index.html
git commit -m "Обновление демо"
git push
```

Через одну-две минуты GitHub Pages покажет новую версию.
